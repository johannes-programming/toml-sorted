Overview
--------

This project sorts TOML data.

Installation
------------

To install ``toml_sorted``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install toml_sorted

Typing
------

This project is strictly typed with ``mypy``.

``toml_sorted.core``
''''''''''''''''''''

``toml_sorted.core.main.main(args: Iterable[str] | None = None) -> int``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This function is the CLI implementation of ``run``.

It accepts these instruction flags, applied in the order given:

.. code-block:: shell

    python -m toml_sorted example.toml --sort --key=foo --all-keys --index=0

turns

.. code-block:: toml

    # example.toml
    [foo]
    bar = [
        [
            4,
            2,
        ],
        {},
    ]
    baz = [
        { a = 9, c = 8, b = 7 },
    ]

into

.. code-block:: toml

    # example.toml
    [foo]
    bar = [
        [
            2,
            4,
        ],
        {},
    ]
    baz = [
        { a = 9, b = 7, c = 8 },
    ]

.. container:: versionchanged

    **Changed in version 2.2:** ``args`` can now be a keywords parameter.

.. container:: versionchanged

    **Changed in version 2.2:** ``main`` now returns an ``int`` exit code.

``class toml_sorted.enum.Selector.Selector``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``ALL_KEYS``
^^^^^^^^^^^^

A path token that, instead of descending into a single key,
expands the current table and applies the remaining path and
the sort to every value.
It is produced by the ``--all-keys`` flag.

``ALL_INDICES``
^^^^^^^^^^^^^^^

A path token that, instead of descending into a single index,
expands the current array and applies the remaining path and
the sort to every value.
It is produced by the ``--all-indices`` flag.
